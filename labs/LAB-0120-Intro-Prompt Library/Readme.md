# Lab — Prompt Library en Microsoft 365 Copilot

**Sesión:** 2 · **Duración estimada:** 25 minutos
**Módulo:** 2 — Ingeniería de prompts y reutilización
**Patrón:** Reutilización de prompts — Prompt Library

---

# Objetivo

Aprender a usar la Prompt Library de Microsoft 365 Copilot para:

✅ descubrir prompts prearmados
✅ reutilizar prompts profesionales
✅ adaptar prompts a tareas reales
✅ guardar prompts personalizados
✅ entender cómo estandarizar interacciones con IA

---

# La situación

Uno de los errores más comunes cuando se empieza a usar IA es escribir prompts desde cero cada vez.

Los usuarios avanzados no trabajan así.

Construyen una biblioteca reutilizable de prompts para tareas frecuentes:

* resumir reuniones
* redactar mails
* generar ideas
* analizar documentos
* crear reportes
* preparar presentaciones

Microsoft 365 Copilot incluye una Prompt Library justamente para eso.

---

# ¿Qué es Prompt Library?

La Prompt Library es una colección de prompts reutilizables dentro de Copilot.

Puede incluir:

* prompts sugeridos por Microsoft
* prompts guardados por el usuario
* prompts compartidos por la organización
* prompts favoritos

La idea es transformar prompts útiles en herramientas reutilizables.

---

# Concepto importante

Un prompt útil no debería escribirse una sola vez.

Debería convertirse en un activo reutilizable.

[Microsoft 365 Copilot Chat](https://m365.cloud.microsoft/chat?utm_source=chatgpt.com)

---

# Paso 2 — Abrir Prompt Library

Dentro de Copilot Chat:

1. Buscar la opción:

```text id="m7q2x4"
Prompt Library
```

o:

```text id="v3n8m1"
Prompts
```

dependiendo de la versión del tenant.

---

# Qué deberías ver

Una colección de prompts organizados por categorías, por ejemplo:

* productividad
* reuniones
* escritura
* análisis
* brainstorming
* gestión de proyectos

---

# Paso 3 — Explorar prompts existentes

Abrí algunos prompts sugeridos por Microsoft.

Por ejemplo:

* resumen de reunión
* generación de ideas
* redacción ejecutiva
* análisis de documentos

---

# Observar

Prestá atención a:

* cómo están escritos
* qué estructura usan
* qué nivel de detalle tienen
* cómo especifican formato y objetivo

---

# Paso 4 — Ejecutar un prompt de la librería

Seleccioná un prompt de resumen o análisis.

Por ejemplo, uno relacionado con documentos o reuniones.

Ejecutalo.

---

# Observar

Identificá:

* qué partes del prompt completó automáticamente Copilot
* si agregó contexto del entorno
* cómo estructuró la respuesta

# Paso 5 — Crear un documento de prueba

🌐 **URL:**
[Microsoft Word Online](https://www.office.com/launch/word?utm_source=chatgpt.com)

---

# Crear documento

Crear un documento llamado:

```text id="q8m2x5"
reporte-lab-prompts
```

Contenido:

```text id="t4n7v1"
Reporte mensual

Problemas detectados:
- aumento de costos cloud
- demoras en testing
- sobrecarga del equipo técnico

Acciones propuestas:
- optimizar infraestructura
- incorporar automatización
- priorizar backlog crítico
```

Esperar unos segundos para sincronización.

---

# Paso 6 — Adaptar un prompt existente

Volvé a Copilot Chat.

Elegí un prompt de análisis o resumen de documentos.

Ahora modificá el prompt para que:

* responda en español
* use bullets ejecutivos
* destaque riesgos
* genere acciones recomendadas

---

# Ejemplo de adaptación

```text id="p1x6m8"
Analizá este documento y generá:

- resumen ejecutivo
- riesgos detectados
- acciones recomendadas
- prioridades inmediatas

Usá formato ejecutivo y bullets.
```

---

# Paso 7 — Citar el documento

Usando `/`, seleccionar:

```text id="d5q2v9"
reporte-lab-prompts
```

Ejecutar el prompt adaptado.

---

# Qué observar

Copilot debería:

✅ leer el documento
✅ interpretar problemas
✅ detectar riesgos
✅ generar recomendaciones accionables

---

# Paso 8 — Guardar un prompt personalizado

Ahora vamos a convertir un prompt útil en un recurso reutilizable.

---

# Crear prompt reusable

Escribí este prompt:

```text id="n7x3m2"
Analizá el recurso citado y generá:

- resumen ejecutivo
- riesgos
- oportunidades
- acciones recomendadas
- prioridades inmediatas

Formato:
- breve
- profesional
- bullets
- orientado a management
```

---

# Guardar prompt

Usá la opción:

```text id="r2m8q4"
Save prompt
```

o:

```text id="k5v1n7"
Add to Prompt Library
```

dependiendo de la versión.

---

# Nombre sugerido

Análisis Ejecutivo de Documentos

La productividad con IA no depende solamente de escribir prompts buenos.

Depende de construir sistemas reutilizables.

La Prompt Library transforma prompts en activos de trabajo:

* reutilizables
* compartibles
* consistentes
* estandarizados

Los usuarios avanzados no empiezan desde cero cada vez.

Construyen una biblioteca de trabajo con IA.
