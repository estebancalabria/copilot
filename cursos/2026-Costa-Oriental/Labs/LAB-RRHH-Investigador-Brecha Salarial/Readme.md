# Laboratorio: Benchmark Salarial y Tendencias de Contratación con el Agente Investigador

## Objetivo

Utilizar el Agente Investigador de Microsoft 365 Copilot para analizar el mercado laboral, investigar tendencias de contratación, identificar competencias demandadas y estimar rangos salariales utilizando información pública disponible.

---

# Escenario

Costa Oriental desea incorporar un Supervisor de Operaciones Logísticas.

Antes de iniciar el proceso de selección, el área de RRHH desea obtener información sobre:

- Competencias más demandadas.
- Tecnologías actualmente requeridas.
- Certificaciones valoradas por el mercado.
- Beneficios ofrecidos por empresas similares.
- Escasez de talento.
- Rangos salariales estimados.
- Recomendaciones para atraer candidatos.

Para obtener esta información se utilizará el Agente Investigador de Microsoft 365 Copilot.

---

# Duración estimada

30 minutos

---

# Requisitos

- Microsoft 365 Copilot
- Acceso al Agente Investigador (Researcher)

---

# Actividad 1

## Abrir el Agente Investigador

1. Acceder a Microsoft 365 Copilot.
2. Seleccionar **Agentes**.
3. Abrir **Investigador**.

---

# Actividad 2

## Investigación del mercado laboral

Ingresar el siguiente prompt:

```text
Investiga el mercado laboral para la posición de Supervisor de Operaciones Logísticas en Uruguay.

Identifica:

- Competencias más demandadas.
- Certificaciones más valoradas.
- Herramientas tecnológicas frecuentemente solicitadas.
- Tendencias actuales de contratación.
- Habilidades emergentes.
- Beneficios más habituales ofrecidos por empresas similares.
- Riesgos de escasez de talento.

Genera un informe ejecutivo e incluye las fuentes utilizadas.
```

---

# Resultado esperado

El agente debe generar:

- Resumen ejecutivo.
- Competencias técnicas requeridas.
- Competencias de liderazgo.
- Certificaciones relevantes.
- Tendencias de contratación.
- Beneficios más frecuentes.
- Fuentes consultadas.

---

# Actividad 3

## Benchmark salarial

Ingresar el siguiente prompt:

```text
Investiga el mercado salarial para la posición de Supervisor de Operaciones Logísticas en Uruguay.

Si existen fuentes públicas confiables:

- Estima un rango salarial.
- Indica las fuentes utilizadas.
- Explica el nivel de confianza de la estimación.
- Diferencia junior, semi senior y senior cuando sea posible.
- Analiza los factores que impactan en la remuneración.

Si no existe información suficiente, explica qué datos faltan para realizar una estimación más precisa.
```

---

# Resultado esperado

El informe puede incluir:

- Rangos salariales estimados.
- Factores que influyen en la remuneración.
- Diferencias por experiencia.
- Diferencias por responsabilidades.
- Comparación entre distintos perfiles.

---

# Aprendizajes Esperados

Al finalizar este laboratorio el participante será capaz de:

- Utilizar el Agente Investigador para investigaciones en internet.
- Obtener información de mercado utilizando fuentes públicas.
- Realizar benchmark salariales asistidos por IA.
- Analizar tendencias de contratación.
- Comparar información interna y externa.
- Optimizar perfiles de puestos.
- Generar recomendaciones estratégicas para RRHH.
