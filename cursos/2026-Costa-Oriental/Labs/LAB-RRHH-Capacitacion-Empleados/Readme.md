# Laboratorio 2: Detección de Necesidades de Capacitación con Microsoft 365 Copilot

## Objetivo

Utilizar Microsoft 365 Copilot para:

- Diseñar una evaluación de desempeño para Costa Oriental.
- Generar automáticamente datos de ejemplo.
- Analizar resultados utilizando Copilot para Excel.
- Detectar brechas de habilidades.
- Proponer acciones de capacitación basadas en evidencia.
- Elaborar un informe ejecutivo para RRHH.

---

# Escenario

Costa Oriental busca profesionalizar la gestión de capacitación de sus colaboradores.

Actualmente no existe un proceso estandarizado que permita identificar necesidades de formación ni priorizar inversiones en capacitación.

El área de Recursos Humanos decide utilizar Microsoft 365 Copilot para diseñar una evaluación de desempeño, generar información de prueba y analizar los resultados para detectar oportunidades de mejora.

---

# Parte 1 – Crear una evaluación de desempeño con Copilot

## Paso 1

Abrir Microsoft 365 Copilot Chat.

Utilizar el siguiente prompt:

```text
Trabajo en Costa Oriental, una empresa logística y de distribución.

Necesito diseñar una evaluación de desempeño anual para identificar necesidades de capacitación.

Genera una plantilla de Excel para evaluar colaboradores de las áreas:

- Depósito
- Transporte
- Operaciones
- Administración
- Atención al Cliente

Incluye competencias técnicas y competencias blandas.

Las competencias deben calificarse del 1 al 5.

Devuelve el resultado en formato tabular para que pueda copiarlo directamente en Excel.
```

---

## Resultado esperado

Copilot generará una propuesta completa para la evaluación de desempeño.

Copiar el resultado a un nuevo libro de Excel.

Guardar el archivo como:

```text
Evaluaciones-Desempeno-Costa-Oriental.xlsx
```

---

# Parte 2 – Generar información de ejemplo

## Paso 2

Abrir Copilot dentro de Excel.

Utilizar el siguiente prompt:

```text
Completa esta plantilla con 100 empleados ficticios de Costa Oriental.

Distribúyelos entre las áreas:

- Depósito
- Transporte
- Operaciones
- Administración
- Atención al Cliente

Genera puntuaciones realistas.

Incluye fortalezas y debilidades diferentes según cada sector.

Asegúrate de que existan áreas con necesidades claras de capacitación para que luego puedan ser identificadas mediante análisis.
```

---

## Objetivo

Que Copilot genere automáticamente un conjunto de datos suficientemente grande para realizar análisis de desempeño y detección de brechas.

Guardar el archivo.

---

# Parte 3 – Análisis inicial de desempeño

## Paso 3

En Excel abrir Copilot.

Utilizar el siguiente prompt:

```text
Analiza esta evaluación de desempeño.

Identifica:

- Competencias con menor puntuación promedio.
- Competencias con mayor puntuación promedio.
- Diferencias relevantes entre áreas.
- Tendencias generales observadas.
```

---

## Preguntas para discusión

- ¿Qué competencias aparecen más frecuentemente con bajo rendimiento?
- ¿Existen diferencias importantes entre sectores?
- ¿Qué conclusiones preliminares pueden extraerse?

---

# Parte 4 – Detección de brechas de habilidades

## Paso 4

Utilizar el siguiente prompt:

```text
Actúa como especialista de Recursos Humanos.

Analiza la evaluación de desempeño y detecta brechas de habilidades.

Para cada brecha identifica:

- Área afectada.
- Competencia.
- Impacto potencial.
- Nivel de prioridad (Alta, Media o Baja).

Justifica cada conclusión utilizando los datos disponibles.
```

---

## Objetivo

Transformar datos de desempeño en información útil para la toma de decisiones de capacitación.

---

# Parte 5 – Definición de necesidades de capacitación

## Paso 5

Utilizar el siguiente prompt:

```text
Basándote únicamente en las brechas detectadas, identifica las necesidades de capacitación de Costa Oriental.

Agrupa las recomendaciones por área.

Prioriza las iniciativas según:

- Impacto en el negocio.
- Cantidad de empleados afectados.
- Riesgo operativo asociado.
```

---

## Objetivo

Convertir hallazgos de desempeño en decisiones concretas de formación.

---

# Parte 6 – Construcción de un plan anual de capacitación

## Paso 6

Utilizar el siguiente prompt:

```text
Diseña un plan anual de capacitación para Costa Oriental.

Incluye:

- Nombre de la capacitación.
- Objetivo.
- Área destinataria.
- Justificación.
- Modalidad.
- Duración estimada.
- Indicador de éxito.

Presenta la información en formato de tabla.
```

---

## Resultado esperado

Copilot generará una propuesta de plan de capacitación alineada con las necesidades detectadas en la organización.

---

# Parte 7 – Elaborar un informe ejecutivo con Copilot Chat

## Paso 7

Subir el archivo Excel a Microsoft 365 Copilot Chat.

Utilizar el siguiente prompt:

```text
Analiza este archivo de evaluación de desempeño.

Genera un informe ejecutivo para la Gerencia de Recursos Humanos de Costa Oriental.

Incluye:

- Resumen ejecutivo.
- Hallazgos principales.
- Competencias más desarrolladas.
- Competencias con mayores oportunidades de mejora.
- Diferencias entre áreas.
- Principales riesgos organizacionales.
- Recomendaciones de capacitación.
- Próximos pasos sugeridos.
```

---

## Objetivo

Transformar un archivo de evaluación en un informe de gestión listo para presentar a la dirección.

---

# Parte 8 – Generación de un plan de acción

## Paso 8

Utilizar el siguiente prompt:

```text
Convierte los hallazgos del informe en un plan de acción para Recursos Humanos.

Para cada acción indica:

- Acción recomendada.
- Objetivo.
- Responsable.
- Prioridad.
- Indicador KPI.
- Riesgo de no implementación.
```

---

# Reflexión Final

Responder las siguientes preguntas:

1. ¿Cuánto tiempo habría llevado realizar este análisis manualmente?
2. ¿Qué valor aportó Copilot durante el proceso?
3. ¿Qué información adicional podría incorporarse?
4. ¿Qué indicadores deberían medirse trimestralmente?
5. ¿Cómo podría complementarse este análisis con Power BI?

---

# Aprendizajes Esperados

Al finalizar este laboratorio el alumno será capaz de:

- Diseñar una evaluación de desempeño con Copilot.
- Generar datos de ejemplo utilizando Copilot para Excel.
- Analizar resultados de desempeño.
- Detectar brechas de habilidades.
- Identificar necesidades de capacitación.
- Crear planes de formación basados en evidencia.
- Generar informes ejecutivos para RRHH utilizando Microsoft 365 Copilot.
