## Historial de Conversaciones

* Las conversaciones quedan en el historial de conversaciones


## Uso de la memoria

* Probemos nuestro primer prompt

```
Haceme un "roast" sobre la informacion que tengas de mi.
```

* La IA tiene "memoria" y va recordando hechos puntales de las conversaciones que han tenido
* Saca informacion de las conversaciones anteriores

* Copilot
   * Abajo a la izquierda en el nombre de usuario  -> Configuracion -> Memoria -> Se puede ver lo que tiene guardado
* Chargpt
   * Abajo a la izquierda en el nombre de usuario  -> Personalizacion -> Memoria -> Se puede ver lo que tiene guardado

# Glosario

* Prompt : Instruccion que uno le da a la IA para que me genere una respuesta
* Modelo de Lenguaje o LLM
* Alucinacion : Cuando la IA inventa, hace suposiciones, contesta cualquier cosa
* Grounding : Anclar la respuesta de la IA en fuentes verificables
