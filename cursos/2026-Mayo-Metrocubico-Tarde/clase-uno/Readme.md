## Tips

### Usar el modo voz

* Usar el modo voz. No es lo mismo

```
Escribime un mail para un cliente ofreciendole comprar un departamento
```
---

* Que esto (Con el modo voz)

```
Escribime un mail para un cliente que le quiero ofrecer un departamento porque le tengo mucha confianza y 100 quiero decirle que es una oportunidad única que no se la pierda sé que él es de de boca entonces quiero tocar su fibra sensible para que compre el departamento diciendo que esto se lo escribí primero a él antes que a nadie trata de ser muy persuasivo porque la verdad sería estoy seguro que si si lo pinchamos el cliente acepta así que démosle fuerza al mail para que sea emotivo y poder venderle
```

### Utilizar ChatGPT como prompt engineering


```
Generame en prompt a partir de esto  : "Quiero que me redactes un informe de desempenio de mi empleado aca va adjunto el word con las observaciones"
```

* Me va a generar

```
Quiero que actúes como un especialista en Recursos Humanos y redacción corporativa.

Tu tarea es redactar un informe de desempeño profesional claro, estructurado y objetivo a partir de la información proporcionada en un documento adjunto (Word con observaciones del empleado).

Indicaciones:
- Analiza cuidadosamente las observaciones incluidas en el documento.
- Redacta el informe en un tono profesional, formal y constructivo.
- Estructura el informe con las siguientes secciones:
  1. Datos generales del empleado (si están disponibles)
  2. Resumen ejecutivo del desempeño
  3. Fortalezas destacadas
  4. Áreas de mejora
  5. Logros relevantes
  6. Nivel de cumplimiento de objetivos
  7. Recomendaciones de desarrollo
  8. Conclusión general

- Evita juicios subjetivos no fundamentados: todo debe basarse en la evidencia del documento.
- Utiliza lenguaje claro, preciso y enfocado al crecimiento profesional.
- Si falta información en algún punto, indícalo explícidamente sin inventar datos.

El resultado debe ser un informe listo para presentar en un contexto corporativo.
```

```

```

```

```
