# Intrucciones

## Contexto

* Toda la informacion que la IA utiliza para darnos una respuesta
  * Prompt e Instruccion
  * Conversacion
    * Tip: Tener en one drive una lista de links de conversaciones habituales
  * Memoria
  * System Prompt o Intrucciones personalizadas
      * La instrucciones que le da Microsoft a Copilot (Es oculto)
      * Las instrucciones personalizadas que si podemos modificar
  * Ultimas Conversaciones
  * One Drive, Calendar, Mails <<<< Microsoft Graph
  * LLamadas a Herramientas
    * Busqueda Web

* Vamos a probar el tema del contexto

```
Hola copilot me podéis hacer un roast una gastada sobre mí con toda la información que que conozcas que sea graciosa y a la vez me haga reflexionar muchas gracias
```
