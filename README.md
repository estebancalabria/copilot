## Sobre este repositorio

Este repositorio centraliza los materiales prácticos de los talleres de Microsoft Copilot dictados por Esteban Calabria. El contenido está diseñado para acompañar sesiones en vivo y puede ser utilizado como referencia posterior a la capacitación.

Los materiales se actualizan de forma continua para reflejar las novedades del ecosistema Microsoft 365 Copilot y sus integraciones.

## Requisitos previos

Para aprovechar los laboratorios necesitás:

- Licencia activa de **Microsoft 365**
- Complemento **Copilot for Microsoft 365** habilitado
- Acceso a **SharePoint / OneDrive** (para labs de agentes)
- Cuenta en [Microsoft Learn](https://learn.microsoft.com) (recomendado)

---

## Contenido típico del taller

Los talleres cubren, según la instancia de capacitación:

| Área | Descripción |
|---|---|
| Fundamentos y arquitectura | Cómo funciona Copilot, Microsoft Graph y seguridad corporativa |
| Prompt engineering | Técnicas para obtener resultados precisos y repetibles |
| Productividad en M365 | Word, Excel, PowerPoint, Teams y Outlook |
| Copilot Agents | Creación, configuración y compartición de agentes personalizados |
| Gobernanza y ética | Supervisión humana, IA responsable y plan de adopción |

> Los casos de uso y ejercicios se adaptan a las necesidades específicas de cada organización.
