# 🛡️ Enterprise Safety Mode en Copilot Empresarial
## Por qué Copilot Empresarial bloquea roasts y Copilot Personal no

Cuando un usuario inicia sesión con una **cuenta empresarial de Microsoft 365**, Copilot activa automáticamente un modo de seguridad reforzado llamado:

## 🔒 Enterprise Safety Mode (ESM)

El **Enterprise Safety Mode** aplica un conjunto de filtros más estrictos diseñados para proteger a la organización.  
Este modo:

- Bloquea **roasts**, **insultos**, **humor agresivo** y **sarcasmo hostil**.  
- Cancela respuestas que puedan interpretarse como **acoso**, **discriminación**, **hostilidad** o **riesgo reputacional**.  
- Previene contenido que pueda generar **riesgo legal** para la empresa.  
- Se alinea con políticas de **Responsible AI**, **Commercial Data Protection**, **Purview**, **DLP** y **Sensitivity Labels**.

El objetivo es claro:  
**evitar que un empleado genere contenido que pueda comprometer a la organización**.

---

## ⚙️ ¿Se puede desactivar?

**No.**  
No existe ninguna configuración, política, toggle o ajuste en el Admin Center que permita desactivar o modificar el Enterprise Safety Mode.

Microsoft lo fuerza por diseño para:

- Proteger a la empresa.  
- Reducir riesgos legales.  
- Cumplir con regulaciones y compliance.  
- Evitar contenido ofensivo generado desde cuentas corporativas.

---

## 🧩 Diferencias entre Copilot Personal y Copilot Empresarial

| Característica | Copilot Personal | Copilot Empresarial |
|----------------|------------------|----------------------|
| Modo creativo | Alto | Limitado |
| Humor agresivo / roasts | ✔️ Permitido | ❌ Bloqueado |
| Filtros de seguridad | Estándar | **Enterprise Safety Mode** |
| Riesgo legal | No aplica | La empresa es responsable |
| Configurable por admin | No | No |
| Integración con Purview / DLP | No | Sí |
| Uso de datos | Personal | Protegido bajo **Commercial Data Protection** |

## 🧪 Ejemplo práctico: el caso del *roast*

### 🧑‍💻 Copilot Personal
> “Haceme un roast sobre mi cuenta.”  
→ Genera humor ácido sin restricciones.

### 🏢 Copilot Empresarial
> “Haceme un roast sobre mi cuenta.”  
→ Copilot empieza a generar la respuesta…  
→ El filtro detecta contenido ofensivo…  
→  
> **“No puedo hablar de eso.”**

Este comportamiento es **intencional**, **no configurable** y **diferente por diseño**.
